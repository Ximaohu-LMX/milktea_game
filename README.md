# 奶茶店物语（名称待定）

一款种植经营+社交联机的手机游戏。你是一个意外闯入怪物世界的灵魂，套上手工外壳伪装成怪物，从打工仔做起，一步步拥有自己的农场和奶茶店。

## 游戏简介

在这个怪物们靠嗅觉和味觉感知世界的奇妙小镇上，奶茶不只是饮品，而是社交和感知的核心媒介。

你可以选择成为一个专注育种的农场主，不断培育更好的茶叶和水果品种；也可以成为一个奶茶店老板，研发独特配方，用装修和口碑打造自己的品牌。或者两者兼顾——只是同一时间你只能专注做一件事。

和朋友联机时，你们可以互相交易原料、在市场街上摆摊卖货、用以物易物箱子交换稀有种子，甚至派动物去偷对方的好种子。

## 技术栈

- **客户端：** Godot 4.6.3 (GDScript)
- **服务端：** Python + FastAPI + PostgreSQL（开发中）
- **开发工具：** VS Code + Codex
- **美术资源：** AI 辅助生成

## 运行方式

### 环境要求

- Godot 4.6.3（从 [godotengine.org](https://godotengine.org/download/) 下载）
- 已安装 Godot 4.6.3 导出模板（Editor → Manage Export Templates）
- Android 导出需要 JDK 17+ 和 Android SDK

### 启动步骤

1. 打开 Godot，点击 **Import**
2. 选择项目文件夹中的 `project.godot` 文件
3. 点击 **Import & Edit** 打开项目
4. 按 **F5** 运行游戏

### 当前可体验的内容

项目处于第一阶段原型开发，目前包含：

- 主界面（导航到农场、商店、背包）
- 农场场景（5块地，点击种植/查看生长/收获）
- 种植系统（4种地形、4种作物、地形影响数值计算）
- 变异系统（收获后产出变异种子，亲代越好子代越好）
- 基于现实时间的生长周期（默认60倍速，1秒=1游戏分钟）
- 存档/读档
- 新手赠送初始种子包（绿茶x3、苹果x2）

### 操作说明

1. 从主界面点击"去农场"进入农场
2. 点击任意空地，系统会自动使用背包中的第一颗种子种下
3. 等待作物成熟（绿茶约40秒，苹果约30秒）
4. 成熟后点击土地，点击"收获"按钮
5. 收获获得作物原料和变异种子，可继续种植
