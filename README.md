# 奶茶店物语 — 游戏设计文档 v5

## 一、游戏概述

一款种植经营+社交联机的手机游戏。玩家通过种植茶叶和水果获取原料，开设奶茶店研发配方、售卖奶茶赚钱。支持好友联机，互相交易原料、扩展菜单。世界观设定为怪物世界，NPC和客人都是各种怪物角色。

**核心体验：** 种植培育的"抽卡"正反馈 + 自由度高的配方研发 + 好友间的经济互动

**平台：** 手机端（Android / iOS）

**技术栈：** Godot 4 (GDScript) + Python 后端 (FastAPI + PostgreSQL) + VS Code + Codex + AI 辅助资源生成

---

## 二、核心机制：同一时间只能做一件事

玩家同一时间只能处于一种状态：务农、打工、或经营店铺。

这是整个经济循环的驱动力——后期玩家想开店就得雇人种地，不能全都自己干。

**例外：** 打工期间可以购买物品和构思菜单（添加配方到草稿）。

---

## 三、玩家分型与游戏节奏

### 3.1 两种玩家路线

**种地型玩家：** 享受育种过程，不断选种→种植→观察变异→培育更好品种。通过出售优质种子和原料致富。他们是种子市场和农产品市场的供给方。

**经营型玩家：** 更喜欢经营奶茶店、研发配方、装修店面、打造品牌。在市场上淘不同属性的原料来制作饮品。他们是农产品市场的需求方，同时通过客人剧情线获取特殊种子和道具，成为稀有交易区的供给方。

两种路线都能玩，也可以混合。分化自然形成了玩家间的交易需求。

### 3.2 三阶段游戏节奏（渐进式放手）

**初期：亲力亲为。** 手动给NPC或其他玩家浇水除草，积攒初始资金。学会种植系统的所有细节。

**中期：宏观规划。** 有了自己的地，设定种植计划雇人执行。种地型玩家开始专注育种，经营型玩家开始筹备奶茶店。

**后期：策略经营。** 田地交给雇工管理，精力转向配方研发、原料交易、种子杂交培育、店面经营、客人剧情线。

### 3.3 阶段过渡的触发

加入叙事引导：打工达到一定次数后，大肥猪主动提出便宜卖地或赠送种子。让玩家感觉是"毕业了"。

---

## 四、两条游戏线

### 线路一：种植线（原料生产）

启动资金/打工赚钱 → 买地 → 买种子 → 种茶叶或水果 → 自己干农活或雇人 → 出售原料/种子 → 赚钱

### 线路二：经营线（奶茶店）

买门面店 → 购买设备（榨汁机、煮茶器等）→ 研发菜单 → 购买原料 → 自己或雇人经营 → 卖奶茶赚钱 → 接待客人触发剧情线 → 获得特殊种子和道具

两条线相互依赖，共同推进。

## 五、赚钱方式

### 1. 打工
- 给其他玩家或NPC的地浇水、收割
- 帮其他玩家或NPC经营店铺
- 不同怪物NPC佣金不同
- 打工时可能触发"田间事件"获得额外收益

### 2. 卖原料
- 种植收获后出售作物（通过市场街摊位或直接卖NPC）
- 作物数值越好，售价越高

### 3. 卖种子
- 优质种子是后期核心交易品
- 种地型玩家的主要收入来源

### 4. 开店卖奶茶
- 卖给NPC怪物客人（基础收入）
- 卖给其他玩家（Buff奶茶）
- 配方品质和原料数值影响销量和回头率

### 5. 出售特殊种子和道具
- 奶茶店客人剧情线赠送的稀有物品
- 在稀有交易区出售，经营型玩家独占的收入来源

## 六、时间系统：周期制

### 6.1 核心原则

不做实时绑定，使用周期制。规定每个阶段要做什么、做几次，不规定什么时候做。

### 6.2 周期结构

一个生长周期（如24小时现实时间）分为若干阶段：发芽期 → 生长期 → 成熟期。每个阶段需要完成一定次数的护理操作（浇水、除草、施肥），阶段内任何时候做都行。

### 6.3 操作灵活度

集中做和分散做对产出有微小差异，给讲究的玩家优化空间，但不做也不亏太多。

## 七、种植系统

### 7.1 地形与土地

| 地形 | 特点 | 适合作物 |
|------|------|----------|
| 高原 | 海拔高，昼夜温差大 | 苹果、高山茶 |
| 平原 | 土壤肥沃，降水适中 | 大多数作物 |
| 热带 | 高温多雨 | 芒果等热带水果、特殊茶叶 |
| 丘陵 | 排水好，地形起伏 | 柑橘类 |

每个地形有5块地，每块地种一包相同数值的种子。

**地形影响因子：** 温度、温差、海拔、降水、土壤类型

### 7.2 作物数值体系

| 数值 | 范围 | 对经营的影响 | 对Buff的影响 |
|------|------|------------|-------------|
| 口味（甜↔酸） | 数值越高越甜 | 回头率 | Buff强度 |
| 香味（浓↔淡） | 数值越高越浓 | 吸引力 | Buff种类倾向 |
| 产量（多↔少） | 数值越高越多 | 成本 | Buff持续时间 |

### 7.3 种植流程

1. 种子初始数值购买/交易时可直接看到
2. 种下后地形影响数值，产物数值在种子基础上受土地因子重算
3. 同一块地上的作物数值相同
4. 数值在一定区间对应一个品种名称
5. 同一大类种子种在不同地形 → 产出不同小品种

**关键：** 种子数值公开透明，但最终产物受土地影响，需要玩家自己计算或查阅记录本。

### 7.4 变异系统

- **正反馈机制：** 亲代数值越好，子代下限越高
- **随机变异：** 小概率出现大幅正向变异
- **跨地形变异：** 不同地形种子种在新地形，可能产生特殊变异
- **自然变异：** 只能产出同一大类下的种子

### 7.5 种子获取途径

| 途径 | 说明 |
|------|------|
| 收获作物 | 获得扦插苗 + 随机变异种子 |
| 养动物偷种子 | 派动物前往别人家，每家偷取数量有限 |
| 市场街购买 | 可直接看到种子初始数值，产物受买家土地影响 |
| 奶茶店客人赠予 | 稀有怪物客人剧情线赠送特殊种子 |
| 以物易物箱子 | 好友间同等级物品交换 |
| 作物变异 | 自然变异或跨地形种植 |

### 7.6 种植手册

- 必须阅读对应大类的种植手册才能解锁种植能力
- 可以提前获得种子（锁定状态，无法种植）
- 手册来源：奶茶店顾客赠予

### 7.7 图标设计规则

- 大类（橘子、橙子、苹果、桃）具有相同基础外形
- 细分品种通过不同颜色和大小区分
- 数值对应视觉表现

## 八、市场街系统

### 8.1 核心理念

市场街是一个可视化的交易场景，玩家在里面走动逛街，看到其他玩家的摊位和奶茶店门面，产生"逛街"的沉浸体验。交易有硬限制（每日上架数量），社交没有限制（关注随便关注）。

### 8.2 街道生成机制

- **按需生成：** 玩家进入市场街时实时生成，从全服在售摊位中随机抽取填充
- **冷却刷新：** 距上次进入超过2小时才会重新生成新街道，2小时内再进入看到的是同一条街
- **过滤售罄：** 生成时只展示仍有库存的摊位，售罄的不显示
- **并发限制：** 每个摊位同时最多出现在有限数量的街道上（如普通摊位5条街，稀有交易区摊位2条街），名额满时不被其他玩家抽到
- **分街区展示：** 按商品等级划分不同街区

### 8.3 并发限制的附带效果

- 热门时段（在线人多）更容易刷到冷门摊位，因为热门摊位街道名额被占满
- 冷门时段反而能刷到好东西
- 不同时间上线的玩家各有机会，不会只有高峰期占便宜
- 稀有商品曝光少，遇到概率低，但遇到了买到概率高

### 8.4 摊位系统

**每个玩家拥有一个摊位：**
- 玩家自行设定摊位每日出售的商品（种子/作物/道具）
- 每日上架商品数量有限（具体数值待定）
- 上架由玩家手动触发，上架后保留24小时
- 24小时后未售出的商品自动下架退回
- 摊位展示3-5件商品的缩略信息，点击进入查看完整库存

**奶茶店门面：**
- 比普通摊位更大更醒目
- 展示菜单招牌、装修风格、今日推荐Buff奶茶
- 点击进入完整的店铺场景，可以购买奶茶

### 8.5 卖家决策

每天上架什么是一个有意义的选择：放极品种子吸引眼球和关注，还是留着走好友以物易物？放性价比高的普通作物走量，还是少量精品高价出售？上架时间的选择也有策略。

### 8.6 街区划分（商品分级）

按商品数值总和分区，玩家从入口依次往里走：

| 街区 | 种子数值总和 | 展位密度 | 买入门槛 |
|------|------------|---------|---------|
| 新手集市 | 0-5 | 最多，热闹 | 无 |
| 良品街 | 6-10 | 较多 | 自产过≥1颗该等级种子 |
| 精品巷 | 11-15 | 较少，精致 | 自产过≥3颗该等级种子 |
| 极品阁 | 16-20 | 少，高端 | 自产过≥5颗该等级种子 |
| 传说堂 | 21+ | 极少，仪式感 | 自产过≥1颗该等级种子 |
| 稀有交易区 | 特殊种子/道具 | 独立区域 | 完成特定客人剧情线 |

- 门槛只认自产种子（通过变异培育出的），从市场购入的不计入
- 农产品（作物原料）不受街区限制，可在任意区域的摊位出售

### 8.7 逛街奖励

- 每天在市场街上走过一定数量的摊位，触发逛街奖励（金币、小道具、随机种子）
- "今日隐藏摊位"：每天有一个特殊NPC摊位随机混在普通摊位中，卖限定品或特价商品，只有逛到才能发现
- 让"逛"本身有不可替代的收益

### 8.8 供给限制与防垄断

- 每个摊位每日上架商品数量有上限
- 稀缺商品库存实时显示，售完即售罄
- 每个摊位同时出现的街道数量有上限
- 不存在无限量出售的情况

## 九、以物易物箱子

### 9.1 核心设定

每个玩家拥有一个以物易物箱子，设置在自己的摊位上。好友访问摊位时可以看到箱子并进行物品交换。

### 9.2 箱子规则

**格子数量：** 最多3个格子，随玩家等级逐步解锁（如初始1格，中期2格，后期3格）。

**物品管理：**
- 玩家可以随时将自己的物品放入箱子的空格中
- 玩家可以随时取出箱子中自己放入的物品
- 格子可以留空，不必全部放满

**交换规则：**
- 好友访问摊位后可以打开箱子
- 交换必须同等级：拿走一件物品的同时必须放入一件同品质等级的物品
- 操作方式：选择箱子中想要的物品 → 从自己背包选择同等级物品放入 → 确认交换

**品质等级统一标签：** 所有物品（种子、作物、道具、特殊种子）统一使用品质标签：普通、良品、精品、极品、传说。箱子中只能同标签交换。

### 9.3 锁定机制

- 当一名玩家打开箱子并进入选择界面时，箱子立即锁定
- 锁定期间其他玩家看到"有人正在交换中"，无法操作
- 操作超时（60秒）未完成交换，自动释放锁定
- 交换完成后立即释放锁定

### 9.4 设计意义

**不产生金币流动：** 好友间只交换物品，不涉及定价，不冲击市场街的定价体系。

**强制等价交换：** 防止老玩家白送新玩家顶级物品的"带号"问题。没有同等级物品就换不到。

**社交温度：** 你在箱子里放了一颗好种子，是给朋友们的礼物。朋友拿走后放回什么是他的心意。约定好的定向交换和随缘的盲盒交换都能在这个机制下发生。

**补充市场街：** 市场街是公开竞争，箱子是朋友间互通有无。两者并行不冲突。

## 十、社交系统

### 10.1 关注系统（类社交软件）

**关注机制：**
- 在市场街逛到喜欢的摊位或店面，可以关注该玩家
- 关注数量不设上限
- 关注后可从关注列表直接传送到该玩家的摊位/店面
- 传送过去也必须等店主上架才能购买，不能绕过上架机制
- 关注列表不影响市场街的随机生成

**关注的本质是社交：** 更多出于对店面装修、品牌风格的兴趣，促进玩家交流。

### 10.2 好友系统

- 好友的摊位/店面可随时从好友列表传送访问
- 好友购买同样受上架限制（有货才能买）
- 好友可以使用对方的以物易物箱子
- 好友间可以私聊约定交易
- 想稳定获得某个卖家的商品 → 需要加好友建立关系

### 10.3 委托制度（异步雇佣）

新阶段开始 → 系统自动发布委托 → 等待期（阶段时长的前70%）→ 有玩家接单由玩家完成 → 无人接单NPC自动兜底

### 10.4 种植计划

玩家自己设定每个阶段的护理方案。不同方案组合影响产出数值。

### 10.5 NPC vs 玩家执行差异

| 执行者 | 效果 |
|--------|------|
| NPC | 标准执行，标准产出，佣金固定偏高 |
| 玩家 | 标准执行 + 概率触发田间事件，佣金自由定价 |

### 10.6 田间事件（仅真人操作触发）

- 发现害虫 → 处理后作物品质+1
- 翻到野生种子 → 额外获得随机种子
- 遇到路过的怪物 → 对话，赠送小礼物
- 土壤状况判断 → 微调操作优化数值

收益由田地主人和干活的人按比例分配。

### 10.7 偷种子

- 派动物前往其他玩家家中
- 每家偷取数量有限
- 轻对抗元素，增加趣味

### 10.8 玩家互访

- 逛别人的农场（看种了什么）
- 逛别人的奶茶店（看装修、菜单、喝Buff奶茶）
- 逛市场街看摊位
- 访问好友摊位使用以物易物箱子

### 10.9 单机兼容

- 所有功能可以对NPC完成
- NPC出售的原料和种子种类固定，限制扩展上限
- 联机是增值体验，不是必须

## 十一、经济体系

### 11.1 双货币

**金币（确定性消费）：** 买地、买门面、买设备、买NPC的基础种子、付NPC佣金。

**种子/作物（玩家间交易品）：** 通过市场街摊位用金币定价交易；通过以物易物箱子等价交换。

### 11.2 经济节奏

- 初期：金币为主（打工赚钱买地）
- 中期：金币与种子并行（开始种植和交易）
- 后期：种子和特殊道具成为核心交易品，金币用于设备升级

### 11.3 完整经济循环

种地玩家 → 市场街摊位卖作物/种子 → 经营玩家购买（金币流向种地玩家）
经营玩家 → 奶茶店卖Buff奶茶 + 稀有交易区卖特殊种子/道具 → 种地玩家购买（金币流回经营玩家）
好友之间 → 以物易物箱子等价交换（不涉及金币，不影响市场定价）
双方 → NPC大肥猪（买地/设备/基础物资 → 金币沉淀消耗）

### 11.4 防通胀机制

- 种子带产地标签，换地形后数值重新计算
- 每周期接收其他玩家种子数量有上限
- 市场街按需刷新 + 2小时冷却控制流通节奏
- 每个摊位每日上架量有限
- 每个摊位同时存在的街道数量有限
- 以物易物箱子只能同等级交换，不产生金币流动
- 种子来源标记"自产"vs"购入"，解锁门槛只认自产

## 十二、奶茶Buff系统

### 12.1 核心设定

玩家喝其他玩家（或NPC店铺）的奶茶可以获得临时Buff。Buff效果与原料数值挂钩。

### 12.2 Buff类型

| Buff类型 | 效果 | 目标用户 |
|---------|------|---------|
| 农活Buff | 增加田间事件触发概率、提升变异出好种子概率 | 种地玩家 |
| 经营Buff | 增加稀有客人出现概率、提升客人满意度 | 经营玩家 |
| 社交Buff | 增加偷种子成功率、委托报酬加成 | 所有玩家 |

### 12.3 平衡限制

- 定位"锦上添花"，提升幅度小，不喝也不影响正常游玩
- 冷却时间：喝完一杯后数小时内不能再喝
- Buff强度由配方+原料共同决定

### 12.4 经济意义

Buff让玩家成为奶茶的消费者，打通经营玩家 → 种地玩家的经济回路。

## 十三、奶茶店经营系统

### 13.1 金币流向

收入：卖奶茶给NPC客人 + 卖Buff奶茶给玩家 + 卖特殊种子和道具
支出：购买原料 + 购买设备 + 店面租金 + 雇佣店员 + 店面装修

### 13.2 店面展示（经营线的社交核心）

**店面装修：** 不同风格的装修主题。装修好的店稀有客人出现概率更高，同时在市场街上更吸引关注。

**菜单命名：** 玩家自己给饮品取名，挂在菜单上其他玩家能看到。

**口碑系统：** 其他玩家来店里喝奶茶可以评价。高评价的店在市场街上出现概率更高。

### 13.3 设备系统

榨汁机、煮茶器、冰沙机等工具，不同设备解锁不同类型饮品制作。设备可升级。

### 13.4 配方研发（待细化）

高自由度配方系统。某些高级配方需要特殊品种作物（来自特殊种子）。

## 十四、客人剧情系统

### 14.1 剧情触发机制

特殊种子和道具通过客人剧情线逐步获得：

- 稀有怪物客人首次来店 → 点普通饮品，简短对话
- 第二次来访 → 更多对话，透露身份和背景
- 第三次来访 → 关系深入，赠送特殊种子或道具
- 后续来访 → 更多稀有物品、解锁新剧情

### 14.2 解锁稀有交易区

完成若干个客人剧情线后，解锁稀有交易区的进入权限。

### 14.3 剧情内容方向

每个稀有怪物有自己的小故事和性格。后续可扩展为完整的怪物图鉴。

## 十五、NPC 设计

### 15.1 大地主NPC —— 大肥猪
- 最重要的NPC，出售土地、门面、基础种子、设备
- 收购玩家的原料和成品
- 负责新手引导和阶段过渡叙事

### 15.2 打工NPC / 雇佣怪物
- 常见怪物角色，同时担任奶茶店客人
- 不同怪物数值和佣金有差距
- 雇佣界面：随机刷出3只怪物供挑选

### 15.3 奶茶店常规客人
- 各种怪物，有不同喜好，提供基础收入

### 15.4 稀有怪物客人
- 有独立剧情线，多次来访推进关系
- 赠送特殊种子、道具、种植手册
- 是解锁稀有交易区的关键

### 15.5 记录官（机械类怪物）
- 后期解锁的功能型NPC
- 自动记录种植数据（种子初始数值、土地情况、产物结果）
- 进阶：生成报表（产出趋势、品种对比、收益统计）
- 高级：推荐种植组合（根据历史数据建议方案）

### 15.6 市场街隐藏NPC
- 每日随机出现在市场街中的特殊NPC摊位
- 出售限定品或特价商品
- 只有逛街才能遇到，制造惊喜

## 十六、记录系统

### 16.1 种植记录本

帮玩家记录每次种植的完整数据：
- 种子初始数值
- 种植地形和土地因子
- 最终产物数值
- 变异结果

方便玩家回顾数据、总结规律、规划下一轮种植。也方便在交易时向买家提供参考。

### 16.2 记录官NPC（机械类怪物）

- 后期解锁，自动记录所有种植数据
- 进阶功能：生成报表
- 高级功能：推荐尝试组合
